## 1. 账号、资质与备案（阻塞）

1. **注册小程序**：[mp.weixin.qq.com](https://mp.weixin.qq.com) → 立即注册 → 小程序，拿到 **AppID**。
2. **选主体**：推荐**企业 / 个体工商户**。个人主体可选类目少、部分能力受限（如支付、部分类目不可用）。
3. **主体认证**（企业一般需，300 元/年）：认证后才能使用更多类目与能力。
4. **ICP 备案**（强制）：mp 后台 → 设置 → **小程序备案**，按指引提交主体与负责人信息并人脸核验，通常 1–20 个工作日。**未完成备案无法提交审核或发布。**
5. **类目**：建议 `教育 → 在线教育` 或 `教育 → 教育信息服务`。类目决定了审核口径，选错是常见驳回原因。
6. **名称 / 头像 / 简介**：名称需唯一且不侵权；本应用建议名称含「俄语学习」便于过审。

> ⚠️ 合规提示：本应用调用大模型生成内容。若面向国内公众提供生成式 AI 服务，需关注《生成式人工智能服务管理暂行办法》相关要求（内容安全、标识、备案等），建议由服务端做内容安全过滤后再返回。此处为产品合规提示，非法律意见。

## 2. 代码侧配置（阻塞）

### 2.1 替换 AppID

`miniprogram/project.config.json`：

```json
{ "appid": "你的 AppID" }
```

### 2.2 配置服务器域名（开发管理 → 开发设置 → 服务器域名）

| 类型 | 需要填写的域名 | 用途 |
|---|---|---|
| request 合法域名 | `https://api.deepseek.com` | AI 补全词条 |
| uploadFile 合法域名 | 你的 OCR 服务域名 | 拍照 OCR（未启用可不填） |

要求：HTTPS、证书有效、默认 443 端口、不能填 IP。域名每月只能修改有限次数，请一次填全。
开发阶段可在开发者工具「详情 → 本地设置」勾选**不校验合法域名**先跑通。

### 2.3 OCR 服务端（可选，但不配会降级）

`miniprogram/config.ts`：

```ts
export const config = {
  ocrEndpoint: 'https://你的域名/api/ocr', // 接收图片，返回 { lines: [{ text, confidence }] }
  demoSeedSize: 1000,
}
```

小程序无法运行 Tesseract.js（无 WASM/Worker、包体受限），OCR 必须走服务端。

### 2.4 AI Key 的安全问题（强烈建议改造）

当前 Key 保存在用户手机本地，请求直达 `api.deepseek.com`：**任何人反编译小程序或抓包都能拿到你/用户的 Key**，且无法做限流与内容过滤。

建议改为服务端代理：

- 小程序只请求你自己的域名（只配 1 个合法域名）；
- 服务端持有 DeepSeek Key，做鉴权、限流、缓存、内容安全过滤；
- 前端只需把 `miniprogram/config.ts` 与 `pages/settings` 的「接口地址」改成你的网关地址（`shared/ai.ts` 已支持自定义 baseUrl 与模型名）。

## 3. 隐私合规（阻塞，且当前代码未完成）

代码里用到了**隐私接口**：`wx.chooseMedia`（相册/摄像头）、`wx.getClipboardData`（读取剪贴板）、`wx.setClipboardData`（写入剪贴板）。

### 3.1 后台配置《用户隐私保护指引》

mp 后台 → 设置 → 服务内容声明 → **用户隐私保护指引**，勾选并说明：

- 相册（选图导入 OCR）
- 摄像头（拍照 OCR）
- 剪贴板（导出备份到剪贴板、从剪贴板导入）

### 3.2 代码接入隐私授权（待补）

`miniprogram/app.json` 增加：

```json
{
  "__usePrivacyCheck__": true
}
```

`miniprogram/app.ts` 增加（示意）：

```ts
App({
  onLaunch() {
    if (wx.onNeedPrivacyAuthorization) {
      wx.onNeedPrivacyAuthorization(() => {
        // 弹窗说明后调用 resolve({ buttonId: 'agree-btn' })，
        // 或用 wx.openPrivacyContract + wx.requirePrivacyAuthorize 组合
        wx.requirePrivacyAuthorize({
          success: () => console.log('用户同意隐私协议'),
          fail: () => console.log('用户拒绝，相关功能不可用'),
        })
      })
    }
  },
})
```

并在「AI 设置 / 统计」页放一个**《用户隐私保护指引》入口**（可用 `<button open-type="openPrivacyContract">`）。未做这一步，正式版调用相册/剪贴板会直接失败。

## 5. 上传 → 体验版 → 提交审核

1. **上传**：开发者工具右上角「上传」，填版本号（建议 `1.0.0`）与备注（如：首发版本，含 OCR/AI 录入、SRS 复习、统计）。
2. **体验版**：mp 后台 → 版本管理 → 开发版本 → 选为**体验版**；「成员管理」添加体验成员，先内部跑一遍。
3. **提交审核**：填写
   - **功能页面路径**：`pages/review/index`、`pages/library/index`、`pages/add/index`、`pages/stats/index`、`pages/settings/index`
   - **测试账号**：无需登录（本应用无账号体系，可注明「无需注册登录，打开即用」）
   - **补充说明**（可直接用这段）：
     > 本产品为俄语学习工具，核心功能是单词/句子的录入（拍照 OCR 或手动输入后由 AI 自动补全释义、词性、例句）、基于间隔重复（SRS）的复习与学习统计。用户数据仅保存在本机设备，未上传服务器，不涉及用户间互动与内容分发。涉及的系统能力：相册/摄像头（用于拍照识别俄语单词）、剪贴板（用于导出/导入学习备份）。
4. 审核通常 1–7 个工作日；被驳回按「审核意见」逐条改后重新提交。

## 6. 发布与发布后

- **发布**：审核通过后在版本管理点「发布」，可选择**分阶段发布（灰度）**降低风险。
- **紧急回退**：版本管理 → 线上版本 → 「回退」到上一个版本（注意回退不可撤销）。
- **监控**：小程序后台「运维中心」看错误与性能；关注 JS 报错率与页面渲染耗时。
- **数据提醒**：学习数据只存在用户手机，**卸载小程序即丢失**，需在产品内提示用户定期导出备份（统计页已提供导出到剪贴板）。
- **版本迭代**：每次改动后重复第 4–5 步；改动 `shared/` 后务必 `npm run sync:shared` 并提交同步结果（CI 会校验一致性）。

## 7. 常见驳回原因与对策

| 驳回原因 | 对策 |
|---|---|
| 服务类目与实际内容不符 | 改选 `教育 → 在线教育`，或在补充说明中明确「俄语学习工具」定位 |
| 未配置用户隐私保护指引 | 按第 3 节配置三个信息项 |
| 调用相册/摄像头但未声明用途 | 在补充说明与隐私指引中写明「用于拍照识别俄语单词」 |
| 涉及 AI 生成内容 | 服务端加内容安全过滤，并在页面标注内容由 AI 生成 |
| 应用存在诱导分享 / 虚拟支付 | 本应用不涉及，若后续加入需补对应资质 |
| 打开即白屏 / 功能不可用 | 检查域名白名单与隐私授权是否完成 |
